# Local analysis materials

This directory is for local reverse-engineering inputs, extracted application
files, and analysis-tool builds. Its contents are ignored by Git because they
include third-party source checkouts, generated build output, and vendor
installer/application files that are not required to build or use this
project.

Keep the repository's reproducible findings and implementation notes in
[`../docs/reverse-engineering.md`](../docs/reverse-engineering.md). Do not add
private, licensed, or generated artifacts here expecting them to be shared
with collaborators.
